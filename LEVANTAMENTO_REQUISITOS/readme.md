## 📋 2. Requisitos Funcionais e Não Funcionais

### Requisitos Funcionais (RF)
* Definem o comportamento e as funções do sistema.
* **Exemplo RF01:** O sistema deve permitir o cadastro de novos usuários.
* **Exemplo RF02:** O sistema deve emitir relatórios de vendas em formato PDF.

### Requisitos Não Funcionais (RNF)
* Definem as restrições, qualidades e propriedades do sistema.
* **Exemplo RNF01:** O sistema deve criptografar as senhas usando SHA-256.
* **Exemplo RNF02:** O tempo de resposta das consultas não deve exceder 2 segundos.

---

## 📊 3. Diagramas na Engenharia de Requisitos

Os diagramas visualizam a estrutura e o comportamento do sistema.

### Principais Diagramas UML Utilizados:
* **Diagrama de Casos de Uso:** Mostra os atores e suas interações com o sistema.
* **Diagrama de Atividades:** Modela o fluxo de trabalho dos processos de negócio.
* **Diagrama de Classes:** Representa a estrutura de dados inicial do domínio.

---

## 📝 4. Técnicas de Elicitação

### 🧠 Brainstorming
* Reuniões criativas e livres de julgamento.
* **Objetivo:** Gerar o maior número possível de ideias de funcionalidades.
* **Fases:** Geração de ideias, agrupamento por afinidade e priorização.

### 👥 Entrevistas
* Conversas diretas e estruturadas com os usuários.
* **Roteiro Básico:**
  1. Qual é o seu maior problema atual no trabalho?
  2. Como você resolve esse problema hoje?
  3. O que não pode faltar no novo sistema?

---

## 🎨 5. Prototipagem

A prototipagem valida os requisitos visualmente antes do desenvolvimento.
* **Baixa Fidelidade:** Desenhos em papel ou wireframes simples para validar fluxos rápidos.
* **Alta Fidelidade:** Telas interativas e fiéis ao design final (ex: Figma) para testar usabilidade.

---

## 📄 6. Relatório Técnico (Estrutura Recomendada)

Documento formal que consolida todos os requisitos do projeto.

1. **Introdução**
   * Objeto do documento.
   * Escopo do sistema.
2. **Descrição Geral**
   * Perspectiva do produto.
   * Funções do produto.
   * Características dos usuários.
3. **Requisitos Específicos**
   * Lista de Requisitos Funcionais (RF).
   * Lista de Requisitos Não Funcionais (RNF).
4. **Modelagem**
   * Diagramas de Casos de Uso explicados.
5. **Anexos**
   * Resultados de entrevistas e atas de *brainstorming*.
