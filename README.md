# 📚 Meu Portfólio de Disciplinas de Tecnologia

Este repositório reúne os materiais de aula, códigos e guias práticos desenvolvidos para quatro disciplinas fundamentais da área de tecnologia. Abaixo está o resumo do escopo de cada uma delas:

---

### 🎓 Engenharia de Requisitos
Focada na fase inicial e estrutural do desenvolvimento de software. Compreende desde a extração de ideias brutas dos clientes até a documentação formal do sistema.
* **Técnicas de Elicitação:** Entrevistas guiadas e sessões criativas de *Brainstorming*.
* **Modelagem:** Divisão entre Requisitos Funcionais (comportamento) e Não Funcionais (restrições), documentados visualmente por meio de Diagramas UML.
* **Validação:** Uso de prototipagem rápida e relatórios técnicos formais.

### 🐧 Sistemas Operacionais e CLI
Aborda o funcionamento interno dos computadores e a administração avançada de sistemas sem dependência de interfaces gráficas.
* **Arquitetura de S.O.:** Compreensão do gerenciamento de processos, memória RAM e armazenamento do Windows e do ecossistema de Distribuições Linux.
* **Operação via Terminal (CLI):** Manipulação profunda de usuários, privilégios administrativos, variáveis de ambiente e arquivos através do Prompt/PowerShell e do Bash.
* **Segurança Cibernética:** Aplicação prática do princípio do menor privilégio e segurança de rede básica.

### 🐍 Lógica de Programação com Python
Introdução ao desenvolvimento de software focado em resolver problemas lógicos utilizando uma das linguagens mais populares do mundo, sempre priorizando a qualidade do código.
* **Fundamentos em Python:** Estruturas condicionais, laços de repetição, funções e coleções de dados.
* **Clean Code & PEP 8:** Escrita de código limpo, legível, modularizado, autoexplicativo e rigorosamente padronizado.
* **Avaliação Formativa:** Criação de um projeto prático e incremental (via terminal) para consolidar os conceitos.

### 🌐 Arquitetura de Internet das Coisas (IoT)
Integração entre o mundo físico e o mundo digital, conectando microcontroladores à nuvem por meio de redes estruturadas.
* **Infraestrutura de Redes:** Diferenciação e aplicação de ativos (roteadores, switches) e passivos (cabos, fibras).
* **Desenvolvimento e Conectividade:** Programação do microcontrolador ESP32 (Wi-Fi integrado) e manipulação de drivers de comunicação.
* **Protocolos de IoT:** Arquitetura do protocolo MQTT (Publish/Subscribe), focado em eficiência e telemetria de sensores, documentado através de relatórios técnicos.
